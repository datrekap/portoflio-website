# Daksh Kapoor — Portfolio

Personal site for [Daksh Kapoor](https://www.linkedin.com/in/daksh-kapoor30), a design engineer and researcher. It covers selected work, experiments, writing, and case studies.

Built with React and Vite. Deployed on Vercel.

## Pages

| Route | Contents |
| --- | --- |
| `/` | Home — intro, selected work, publications |
| `/work` | Project index (product design, engineering, research, motion) |
| `/about` | Bio, photos, experience |
| `/play` | Experiments and motion studies |
| `/public-future-arts-lab` | FultonBrighterFutures case study |
| `/sitehub-2` | SiteHub 2.0 / PropertyWorks case study |
| `/parkwise` | ParkWise case study |
| `/trojanstep` | TrojanStep case study |

## Stack

- React 18 and React Router
- Vite
- Tailwind CSS
- GSAP, Framer Motion, Lenis
- Three.js / React Three Fiber
- Vercel Analytics

## Run locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

```bash
npm run build      # production build to dist/
npm run preview    # serve the production build locally
```
